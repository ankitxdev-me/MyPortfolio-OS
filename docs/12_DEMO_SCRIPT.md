# 35. Troubleshooting During Demo

If something fails

- Stay calm
- Explain the issue honestly
- Switch to a backup environment if available
- Use screenshots or recorded demos if necessary
- Continue the presentation without focusing on the failure

Never spend excessive time debugging during a live demonstration.
